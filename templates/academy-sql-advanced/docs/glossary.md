# Glossary

- **Grain** - what one row represents.
- **Idempotence** - rerunning the same operation produces the same result.
- **Sargable predicate** - a filter that lets the engine use the stored ordering or partition key.
- **Late-arriving data** - a row whose ingestion time is later than its business time.
- **SCD2** - a slowly changing dimension that keeps historical versions with validity windows.
- **Reconciliation** - an independent comparison between a result and its source of truth.
