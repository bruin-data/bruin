# Social listening

The social-listening template is a warehouse-first, safe-by-default workflow for public-conversation discovery, explainable qualification, review routing, and draft-only replies.

It includes a zero-credential DuckDB demo, compliant source-adapter interfaces, idempotent webhook outbox, data-quality checks, and draft-first Bruin Cloud agent definitions. Its complete setup, source/privacy policy, canonical model, safety model, and troubleshooting guide ship with the template in `docs/index.md`.
